# Onboarding

This section helps new contributors and users ramp up based on their role.

Use the guide that matches your main responsibilities:

- [Developer onboarding](developer.md)
- [Maintainer onboarding](maintainer.md)
- [Operator onboarding](operator.md)

## Quick map

- If you write or modify profiles, start with developer onboarding.
- If you review, release, and steward quality, start with maintainer onboarding.
- If you run the tool to generate deployment configs, start with operator onboarding.
